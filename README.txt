FILES
- index.html: website content
- style.css: design and responsive layout
- script.js: mobile navigation and footer year

HOW TO PUBLISH WITH GITHUB PAGES
1. Sign in to https://github.com/Madhumitha-02
2. Click the + icon > New repository.
3. Repository name: madhumitha-portfolio
4. Choose Public, then click Create repository.
5. Extract this ZIP on your computer.
6. In the new GitHub repository, click Add file > Upload files.
7. Upload index.html, style.css, script.js and README.txt (upload the files, not the ZIP).
8. Click Commit changes.
9. Open Settings > Pages.
10. Under Build and deployment, choose Deploy from a branch.
11. Select Branch: main and Folder: /(root), then Save.
12. Wait a minute or two. Refresh the Pages screen; GitHub will show your live website link.

Your link will look like:
https://madhumitha-02.github.io/madhumitha-portfolio/
